# Project Overview
This project performs inferential statistical analysis on health records.

# Topics Covered
- Hypothesis Testing
- Confidence Interval
- Z-Test
- T-Test
- Chi-Square Test
- ANOVA
- Covariance
- Correlation

# Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Statsmodels

# Dataset Features
- Age
- Weight
- BMI
- Blood Pressure
- Smoking Status
- Diabetes
- Hypertension

# Output
- Statistical test results
- Graphs
- Interpretations
- CSV dataset
